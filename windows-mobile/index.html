▣ EMULADOR x86 · v86
Emulación real de PC en el navegador. Inicia FreeDOS como sistema libre de prueba. También puedes elegir una imagen de disco o ISO propia que tengas derecho a usar. Windows moderno y Ollama 8B no funcionarán aquí a velocidad nativa.
Emulador sin iniciar. Descarga el motor v86 al arrancar.

Dependemos de los archivos públicos v86 y la imagen FreeDOS alojados por el proyecto original. Si el navegador bloquea las descargas cruzadas, prueba su demostración oficial. La emulación consume CPU del teléfono y puede ser lenta.

ⓘ DEXTER MOBILE OS
Este es un entorno web propio inspirado en un escritorio Windows: no es Windows instalado. Sus componentes principales son una interfaz original, WebLLM para IA local y v86 para PC x86 emulado. Cada uno es independiente.

La emulación de Windows antiguo requiere que aportes una imagen del sistema con la licencia correspondiente. No distribuimos Windows ni modificamos iOS. El modelo de IA predefinido es distinto del WormGPT original, por sus requisitos de memoria y formato.

Limitación comprobada: un plugin marcado como Desktop only requiere la aplicación ChatGPT para escritorio; no basta con cambiar el agente de usuario ni abrir ChatGPT Web dentro de una PC virtual. Tampoco es posible instalar plugins silenciosamente desde esta página.

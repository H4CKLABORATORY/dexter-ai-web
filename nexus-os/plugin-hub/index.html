Flujo recomendado

  1. 1Pide en ChatGPT el plugin o la integración que necesitas.
  2. 2ChatGPT puede buscar opciones compatibles y ofrecerte la instalación mediante sus propias herramientas cuando estén disponibles.
  3. 3Autoriza la instalación y conexión cuando el producto o el proveedor lo soliciten.
  4. 4Utiliza Remote PC solo cuando te ayude trabajar en un navegador de escritorio.
Limitación comprobada: un plugin marcado como Desktop only requiere la aplicación ChatGPT para escritorio; no basta con cambiar el agente de usuario ni abrir ChatGPT Web dentro de una PC virtual. Tampoco es posible instalar plugins silenciosamente desde esta página.

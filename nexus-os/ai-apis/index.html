Conectar un modelo

Selecciona un modelo en el catálogo. Generaremos un archivo opencode.json sin secretos, listo para copiar. La clave privada se añade posteriormente con /connect dentro de OpenCode.

Selecciona el botón «Configurar» de cualquier modelo para preparar la conexión.
opencode.jsonSolo configuración pública




Copia el JSON a la configuración de tu proyecto y conecta una clave válida en OpenCode. Algunos proveedores utilizan formatos de API distintos y requieren configuración específica; verifica las instrucciones antes de utilizar el archivo.








Acceso gratuito no significa clave pública


El catálogo enumera endpoints y modelos publicados. Sus límites, requisitos y disponibilidad pueden cambiar. Las llamadas de IA requieren un proveedor activo y, normalmente, credenciales propias; nunca pegues una clave privada en el código público o en comentarios de GitHub.

NEXUS / CHATGPT NATIVE DESKTOP

Tu ChatGPT de PC, en el iPhone.

Una conexión real a una computadora Windows con la aplicación oficial de ChatGPT. No se emula ni sustituye ChatGPT Desktop con una página web. El iPhone recibe la pantalla de Windows y permite controlarla desde Safari.

Preparado para conectar a un Windows real
⊞

Instalar ChatGPT en Windows

Haz esto una sola vez en tu computadora Windows 10/11 o en una máquina virtual Windows que ya tengas. El instalador usa Microsoft Store; tú debes iniciar sesión.

Descargar ChatGPT oficial ↗ Script de instalación ↗

El script de GitHub puede ejecutarse en PowerShell desde el propio Windows después de descargarlo y revisarlo. No instala el acceso remoto sin tu consentimiento.

▣

Abrir tu Windows desde Safari

DWService permite conectarte a una PC real desde un navegador. Para la conexión permanente, la máquina debe tener DWAgent instalado y estar encendida.

Abrir Windows remoto ↗ Instalar DWAgent ↗

La pantalla se abre en la página oficial de DWService; NEXUS no solicita ni almacena contraseñas, tokens ni datos de la sesión.

TIPOS DE COMPUTADORA

¿Dónde funciona?

Windows en tu casa

No necesita servidor de pago, pero la computadora debe permanecer encendida y conectada a internet.

Windows en la nube

Funciona sin tu PC personal, pero requiere aprovisionar una VM Windows real con almacenamiento persistente y normalmente facturación.

Importante: NEXUS OS está alojado en un servidor web Linux, que no puede ejecutar la app oficial de ChatGPT para Windows. Esta página es el puente de acceso, no una PC creada ni un Windows remoto ya encendido. Habilita la verificación en dos pasos y nunca compartas el acceso a tu computadora.

Puedes instalar un plugin «Desktop only» únicamente cuando la aplicación de escritorio y tu cuenta cumplen sus requisitos. La conexión a servicios de terceros sigue necesitando las autorizaciones correspondientes.

NEXUS / EMULATION

Retro Core

Biblioteca de ROM integrada

Biblioteca homebrew con cartuchos NES y Game Boy de distribución autorizada. Prioridad: plataformas y aventuras. Los juegos se ejecutan en tu teléfono mediante EmulatorJS; la primera vez hay que descargar el núcleo del emulador. Los juegos oficiales de Mario requieren licencia y no vienen incluidos.

🪐↗NEXUS JUMP — AVENTURA DE PLATAFORMASJuego original para iPhone · 3 mundos · controles táctiles · sin ROM ni descarga adicional

Mis ROM privadas del iPhone

Importa las ROM que tengas derecho a utilizar y guárdalas en este dispositivo. Aparecerán aquí cuando regreses sin que tengas que seleccionarlas otra vez. No se suben al servidor, ni al repositorio de GitHub.

Tus archivos permanecen exclusivamente en el almacenamiento de Safari o de la app instalada.

Safari puede eliminar datos locales si falta espacio. Conserva una copia de tus ROM originales en Archivos o en tu almacenamiento personal. La biblioteca no crea copias de seguridad online.

Selecciona uno de los juegos incluidos para comenzar.

Los juegos de consola suelen incluir controles táctiles de EmulatorJS. Si Safari no admite un núcleo o un archivo, el experimento puede fallar. No cargues archivos con datos personales.

NEXUS / PC RETRO

FreeDOS PC

Sistema real de PC retro incluido

Una imagen FreeDOS distribuible y el motor x86 v86 ya forman parte de esta aplicación. Se emula un PC antiguo en el navegador; no es Windows 7 ni Windows 10 real y no ejecuta programas modernos.

Listo para cargar la BIOS y el disco FreeDOS preinstalados.

El motor x86 usa WebAssembly y CPU de tu dispositivo; en iPhone algunos métodos de teclado o vídeo pueden fallar. Si el arranque no aparece, mostramos el diagnóstico sin fingir que Windows está instalado.

NEXUS / ANDROID LAB

Android Lab

Launcher futurista, con ruta a Android real

Esta interfaz tiene apariencia de un launcher Android, pero se ejecuta como web. Los juegos de Neon Arcade son aplicaciones web reales. Para instalar APK y ejecutar Android completo necesitaremos una instancia externa con Android y streaming WebRTC; no existe aún.

ANDROID CLOUD: SIN SERVIDOR CONECTADO · Juegos HTML5 incluidos, pero no APK ni una imagen Android.

Arquitectura prevista para el servidor

Android Linux mediante redroid o Anbox Cloud → WebRTC autenticado → pantalla y controles dentro de NEXUS OS. Las partidas y datos se guardarán en almacenamiento privado, no en páginas públicas.

No es posible ejecutar aplicaciones APK nativamente dentro de Safari mediante una simple PWA o un perfil de configuración.

NEXUS / DATA

Data Vault

Partidas y almacenamiento

Los récords y notas se guardan en este dispositivo. Puedes exportar un respaldo JSON y restaurarlo en otro. Sincronización online aún no configurada. El almacenamiento en nube sincroniza datos, pero no hace más rápida la CPU del teléfono.

Preparación para guardado online

La estructura de datos ya admite exportación e importación para migrar más adelante a una API con cuentas, autenticación, cifrado y almacenamiento privado. Todavía no se transmiten partidas ni notas a un servidor.

DEXTER NEXUS / INSTALL

Instalar en tu pantalla de inicio

En iPhone abre esta web en Safari, toca Compartir y selecciona «Añadir a pantalla de inicio». Después, «Abrir como app» si aparece. Tendrá su propio icono y ventana. No necesita perfil especial ni una firma IPA.

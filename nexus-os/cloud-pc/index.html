Tu computadora en el iPhone.

¿No tienes una PC física? Puedes usar un entorno de desarrollo Linux con PowerShell auténtico mediante GitHub Codespaces, sujeto a cuota gratuita mensual. También conservamos las opciones para controlar una PC Windows propia.

▣ PowerShell Cloud · Sin computadora física

Inicia una máquina virtual de desarrollo desde Safari. PowerShell 7, Node.js y OpenCode configurados para tu proyecto DEXTER, con acceso a la terminal y al código desde el iPhone. No es Windows ni ejecuta programas .exe.

Abrir PowerShell Cloud ↗Crear Codespace ↗

Se requiere inicio de sesión en GitHub. La máquina se detiene al quedar inactiva y está sujeta a límites gratuitos.

Otras opciones gratuitas · Requieren una PC Windows encendida
🖥️

Chrome Remote Desktop

Opción más sencilla para tu PC. Instala el acceso remoto una sola vez desde Windows y después contrólala desde el iPhone con tu cuenta de Google y un PIN.

Conectar mi PC gratis ↗Guía iPhone ↗

Sin suscripción de escritorio remoto. Requiere internet y que la PC esté encendida.

🌐

DWService

Alternativa gratuita desde Safari. Instala DWAgent en tu Windows, vincula tu cuenta y accede a la pantalla desde el navegador del teléfono.

Abrir DWService ↗

El plan gratis de DWService permite hasta 6 Mbps de ancho de banda.

Configuración en 3 pasos

1. En tu Windows, abre Chrome Remote Desktop y configura el acceso con tu cuenta y PIN.
2. Desde el iPhone, abre este mismo enlace y selecciona tu computadora.
3. En el Windows remoto, abre la aplicación oficial de ChatGPT e inicia sesión. Los plugins compatibles con escritorio seguirán sujetos a sus requisitos y aprobaciones.

La computadora tiene que estar encendida y conectada a internet. No compartas tu PIN ni tus contraseñas. NEXUS OS solo enlaza a los proveedores oficiales: no almacena credenciales ni controla tu computadora por sí mismo.

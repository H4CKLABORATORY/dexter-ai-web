Tu PowerShell en el iPhone.

Sin PC física. Abre una máquina virtual de GitHub Codespaces, entra a su terminal y ejecuta PowerShell 7 auténtico, Git, Node.js y OpenCode. No es una copia de Windows: los programas .exe de Windows y sus controladores no funcionan aquí como en una PC.

Iniciar computadora virtual

Usa el repositorio del proyecto DEXTER. PowerShell y Node.js están configurados para instalarse en tu Codespace. Es necesario iniciar sesión en GitHub y confirmar la creación del entorno.

Abrir PowerShell Cloud ↗ Mis máquinas virtuales ↗

GitHub ofrece cuota gratuita mensual para cuentas personales, pero no una VM ilimitada 24/7. La máquina puede detenerse por inactividad o al agotarse la cuota.

1. Terminal real

Una vez que abra VS Code dentro del navegador de tu iPhone, busca Terminal → New Terminal. Debería iniciarse PowerShell automáticamente. También puedes escribir:

pwsh
$PSVersionTable
Get-Location
Get-ChildItem

2. Abrir servidor OpenCode

Ejecuta el script incluido. Solicita una contraseña y abre el servidor en el puerto 4096. No muestra una dirección inventada.

pwsh -File ./scripts/start-opencode-mobile.ps1

3. Conseguir la URL del iPhone

  1. En el Codespace abre la pestaña PORTS / PUERTOS y localiza el puerto 4096.
  2. Copia su enlace HTTPS, similar a https://nombre-del-codespace-4096.app.github.dev. Este texto es un ejemplo, no una URL activa.
  3. El puerto es privado por defecto. Algunas apps externas de OpenCode Mobile no pueden autenticarse con la sesión GitHub de un puerto privado. Para conexiones externas puede ser necesario hacerlo público, solo con la contraseña fuerte del servidor activada. Esto expone el servicio a Internet y conlleva riesgos.
  4. En OpenCode Mobile introduce la URL real. Si tu versión necesita un plugin con túnel y QR, revisa los pasos siguientes.
Seguridad: nunca publiques claves ni tokens en el repositorio. No compartas la contraseña de la terminal o el enlace de acceso. Si el cliente móvil no acepta autenticación HTTP Basic, no desactives la contraseña para forzar una conexión.
La aplicación me pide código QR y plugin /mobile

La app que muestra “Install the OpenCode plugin” podría requerir el complemento separado opencode-mobile. En la terminal del Codespace ejecuta el instalador del proyecto y configura el túnel que te indique. Después inicia OpenCode y usa /mobile para obtener el QR o la URL. Ese túnel es distinto del puerto de Codespaces.

npx opencode-mobile install
opencode
# Dentro de OpenCode escribe: /mobile

Verifica el complemento que utiliza tu versión de la app antes de concederle acceso. Un Codespace no proporciona un servidor permanente ni garantiza que el plugin funcione sin configurar un túnel.

¿Puedo instalar PowerShell directamente en iOS sin nube?

Puedes instalar un terminal Unix local, como a-Shell, para ejecutar comandos compatibles, Python, Git y otras herramientas disponibles para iOS. No equivale a PowerShell 7 ni ejecuta programas Windows. Para PowerShell real sin PC física, aquí usamos la máquina virtual en la nube.

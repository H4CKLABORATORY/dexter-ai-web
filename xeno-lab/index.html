Classical / quantum inspired

Optimización tipo recocido simulado

Prueba sustituciones monoalfabéticas A–Z guiadas por un modelo de n-gramas españoles. Busca mejores puntuaciones; no convierte un texto desconocido en español ni ejecuta física cuántica.

El resultado será una hipótesis estadística, no una traducción validada.

Qué significa «modo cuántico»

El optimizador calcula una función de puntuación y acepta ocasionalmente cambios peores para escapar de máximos locales.

Esta técnica se ejecuta en CPU normal. Un procesador cuántico real no se puede crear por software, y en este problema no se ha demostrado ventaja cuántica. El algoritmo sirve para generar hipótesis que luego hay que probar contra evidencia independiente.
